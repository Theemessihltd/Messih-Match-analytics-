# Messih Match Analytics

AI-powered football match analysis and prediction platform.

## Stack
- Next.js + TypeScript + Tailwind-ready frontend
- Node.js + Express API
- PostgreSQL-ready data layer
- Python FastAPI AI service scaffold

## Run the web app
cd apps/web
npm install
npm run dev

## Run the API
cd apps/api
npm install
npm run dev

The AI service is scaffolded separately in `apps/ai`.
